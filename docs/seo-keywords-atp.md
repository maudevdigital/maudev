## Ideas de blog pendientes (por volumen y afinidad)

1. **"Página web con IA: qué puede hacer por tu negocio en 2026"** (140/mes) —
   chatbots, respuestas automáticas, calificación de leads. CTA a diagnóstico.
2. **"¿Cuánto cuesta una página web con carrito de compras en Chile?"** (140+70)
   — comparar plantilla vs a medida, costos reales de Webpay/MercadoPago.
3. **"Metodologías de desarrollo de software explicadas para no técnicos"**
   (140) — Scrum, cascada, por qué importa al contratar.
4. **"Wix vs página web a medida: cuándo conviene cada una"** — "página web wix"
   tiene 590/mes; capturar comparación honesta (estilo ComparisonSection).

## Notas

- Las preguntas puras tienen poco volumen individual (~10/mes) pero en conjunto
  alimentan el FAQ (rich results FAQPage ya activo en el home).
- Reponer datos: crear búsquedas nuevas vía API (POST /api/public/v1/searches,
  body {keyword, region:"cl", language:"es"}; key en .env.local
  ANSWERTHEPUBLIC_API_KEY). Proveedores útiles: gweb, tiktok, youtube.
